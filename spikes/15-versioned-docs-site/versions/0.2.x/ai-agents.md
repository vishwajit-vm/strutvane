Strutvane's conventions (one place for each kind of file, migrations as the source of truth, `node strut make:*` generators) make it predictable for AI coding agents. Every docs page has **Copy as Markdown**, and each version publishes `llms.txt`. A dedicated `@strutvane/agent-tools` package comes later.
