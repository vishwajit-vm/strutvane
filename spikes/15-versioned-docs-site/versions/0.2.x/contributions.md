---
title: "Contribution Guide"
description: "How to report bugs, propose changes and fix the docs, and which branch each change goes to."
---

Strutvane follows Laravel's branch rules: bug fixes go to the oldest supported line that has the bug (for example `0.2.x`), new features that don't break anything go to the current line, and breaking changes go to `main`. Docs live on the same branches as the code, so a docs fix for 0.2 goes to `0.2.x`. Use the "Edit this page" link at the bottom of any page to start.
