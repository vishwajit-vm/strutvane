---
title: "Pagination"
description: "Splitting results into pages, with totals or with cursors."
---

Offset pagination with totals and cursor pagination are both built in. The generated API caps pages at 100 rows and always uses a deterministic order; the UI shows 25 rows per page by default (10, 25, 50 or 100).
