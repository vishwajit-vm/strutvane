title: "Starter Kits"
description: "The stacks `npm create strutvane@latest` can set up for you: a full-stack app, an API only, or a UI only."
---

The installer asks what you are building. **Full-stack** gives you the API plus the React admin app with generated screens. **API only** skips the UI. This page will compare them and show how to add the UI later with `node strut install:ui`.
