title: "Frontend"
description: "How the React UI is served next to your API, and how to write your own pages and components."
---

A full-stack Strutvane app serves the API and a React 19 + Vite + Tailwind UI on one port, with hot reload, when you run `npm run dev`. The components are shadcn-style files that live in your app, so you can change any of them.
