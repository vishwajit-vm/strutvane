# Shelved (2026-11-15)

This design direction ("Glass") was stopped part-way through when the project lead chose two other designs:
- **Crisp** (spike 19), the default;
- **Vivid** (spike 17).

It is kept, not deleted, as the first candidate for a future `@strutvane/design-glass` package (blueprint §5.1).

The code is unfinished and has not been reviewed. It is not production code, and nothing here is published.
