# Code of Conduct

Strutvane adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct for all repositories, issues, discussions and community spaces.

**In short:** be respectful, assume good intent, welcome newcomers, and keep discussions constructive and on-topic. Harassment of any kind is not tolerated.

**Reporting:** to report unacceptable behaviour, contact the maintainers privately through the repository owner's GitHub profile. Reports are handled confidentially.
